# Rustic: investigación para port Fabric 26.3

**Proyecto incompleto: no es una versión jugable.** CI compiló el código de desarrollo y ejecutó pruebas limitadas en Minecraft; no hay paridad ni versión final. No poner las copias Forge de `original/` en la carpeta de mods de 26.3. Hay configuración Fabric y código inicial para seis ingredientes, tres alimentos (uvas, bayas y aceitunas) y una pestaña agrícola parcial y tres recetas de fundición, además de texturas originales e idiomas convertidos; la mayoría de la funcionalidad y las pruebas de paridad siguen pendientes.

`original/rustic-pre-1.2.0` y `original/rustic` conservan revisiones upstream distintas; `original/wiki` contiene la wiki upstream. No son código Fabric. Las condiciones de atribución y licencia deben confirmarse antes de distribuir el port; véase [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) y el progreso.

La configuración de desarrollo apunta a Java 25, Minecraft 26.3 y Fabric. [CI](https://github.com/ripblackdragon-cyber/rustic/actions/runs/41121118254) compiló el commit `0c87441` y ejecutó pruebas en un servidor GameTest, un cliente gráfico con servidor integrado y un servidor dedicado de prueba, usando código de desarrollo. El JAR de desarrollo, los informes y una captura están en los artefactos de esa ejecución hasta el 6 de noviembre de 2026; no son una entrega final. El sandbox no puede descargarlos por restricciones de red. Faltan pruebas con dos jugadores, del JAR instalado, JEI y paridad funcional. Los detalles y limitaciones están en [el informe de pruebas](RUSTIC_TEST_REPORT.md).

Para regenerar los índices se necesita Python 3: `python3 tools/inventory.py`, `python3 tools/recipe_audit.py` y `python3 tools/registry_audit.py`. `python3 tools/migrate_languages.py` y `python3 tools/migrate_textures.py` comprueban las copias; con `--write` crean solo archivos que falten y no sobrescriben diferencias. `python3 tools/verify_upstream.py` verifica las referencias; `python3 -m unittest discover -s tests -v` prueba las herramientas. El [control de recetas](audit/README.md) devuelve fallo mientras existan entradas pendientes. Estas comprobaciones no prueban cobertura completa ni funcionamiento en Minecraft.

Las pruebas de servidor se ejecutan con `./gradlew runGameTest` y las de cliente con `./gradlew runClientGameTest` en un entorno gráfico compatible. `./gradlew build` incluye las pruebas de servidor. El servidor dedicado de la prueba de cliente solo se activa con `-PacceptMinecraftEula=true`, que acepta la [EULA de Minecraft](https://aka.ms/MinecraftEULA); no activar esa opción sin haberla aceptado. El usuario autorizó expresamente su uso para las pruebas temporales de CI.
